# Rock Paper Scissors

A console game written in Python where you play against the computer.

## Features
- Computer picks randomly using the `random` module
- Compares choices and prints the result
- Uses functions and a dictionary to organise the code

## How to run
1. Install Python 3
2. Download `rps.py`
3. Run `python rps.py` in your terminal

## What I learned
Functions, dictionaries, conditionals and the random module.
